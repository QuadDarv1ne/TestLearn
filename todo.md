## Обновления функционала (2026-04-27)

### Новые модели данных
- `LeaderboardEntry` - запись в таблице лидеров
- `Certificate` - сертификат о прохождении курса
- `Comment` - комментарий к теме
- `Notification` - уведомление пользователя

### Новые сервисы
- `LeaderboardService` - управление таблицей лидеров
- `CertificateService` - генерация сертификатов
- `CommentService` - управление комментариями (добавление, получение, лайки)
- `NotificationService` - управление уведомлениями

### Новые API endpoints
- `GET /api/leaderboard` - таблица лидеров
- `GET /api/certificate` - получение сертификата пользователя
- `GET /api/comments/{topic_id}` - комментарии к теме
- `POST /api/comments` - добавить комментарий
- `POST /api/comments/{comment_id}/like` - лайк комментария
- `GET /api/notifications` - непрочитанные уведомления
- `POST /api/notifications/{notification_id}/read` - отметить как прочитанное
- `GET /stats/export/pdf` - экспорт прогресса в PDF

### Новые таблицы БД
- `comments` - комментарии к темам
- `notifications` - уведомления пользователей

### Новые JavaScript файлы
- `static/js/gamification.js` - геймификация (уровни, достижения, ежедневные вызовы)
- `static/js/social.js` - социальные функции (комментарии, уведомления, таблица лидеров)
- `static/js/base.js` - базовые утилиты (Toast, Loading, Storage, API)
- `static/js/theme.js` - управление темой (светлая/тёмная)
- `static/js/search.js` - расширенный поиск с подсветкой
- `static/js/quiz.js` - таймер и навигация в викторинах
